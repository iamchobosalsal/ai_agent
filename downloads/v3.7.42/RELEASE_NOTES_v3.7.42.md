# v3.7.42 — 초보자용 런처에도 반복 입력·Windows 작업 지연 개선 적용

2026-09-07. v3.6.94의 검증된 공통 변경을 v3.7에 적용한 배포판입니다. v3.6.94 파일과 별도 Team AI는 변경하지 않습니다.

## 변경 사항

- LM Studio 컨텍스트 체크포인트를 4개로 설정하고 로딩 검증도 일치시켰습니다. 지원 모델은 후속 도구 호출에서 반복 입력의 중간 상태를 재사용할 수 있습니다. 모델 종류·대화 길이·추론/출력 예산을 줄이지 않았습니다.
- Hermes의 짧은 안내문에 Windows 로그 분석기·ZIP 사진 정리기의 실제 설치 경로와 호출 방법을 복구했습니다. 특정 질문 문자열에 맞춘 분기나 답변 삭제 규칙을 추가하지 않았습니다.
- 로그 조회에 시간·수량 제한을 직접 적용하고 한글 UTF-8 출력, 정상 빈 결과와 권한 오류 구분, 반환된 재부팅 기록 보존을 보완했습니다.
- 해당 보조 스크립트 실행에만 `-ExecutionPolicy Bypass`를 지정합니다. 시스템 전체 실행 정책을 바꾸거나 관리자 권한을 자동으로 높이지 않습니다.
- 사진 정리기는 파일명 날짜 또는 수정일 기준 월별 정리, 원본 ZIP·비미디어 파일 보존 및 동명 파일 충돌 처리를 안내합니다. EXIF 촬영일 판독 기능을 추가한 것은 아닙니다.
- v3.7 초보자용 UI·모델 선택·기본 설정과 기존 `/rag` 경로는 유지합니다. 추가 검색·재임베딩·검수 모델 호출은 없습니다.

## 검증 범위와 한계

- 공통 코드의 v3.6.94 적용본과 일치 여부, v3.7 변경 범위, 로그 수집기의 7개 회귀 항목 및 기존 빌드 검사를 확인합니다. 실제 배포 EXE의 내장 런타임, 서명·타임스탬프·해시와 사용자 데이터 미포함도 별도로 검사합니다.
- 앞선 v3.6 동일 Qwen 3.6 35B-A3B 모델·약 1.55만 입력 토큰 비교에서 후속 질문 7.028초 → 0.206초, 정정 질문 7.054초 → 0.224초였고 답은 일치했습니다. 첫 질문은 6.971초 → 7.128초였습니다. 이는 공통 변경의 참고 측정이며 **v3.7에서 새로 측정한 속도나 모든 모델의 보장치가 아닙니다.**
- 앞선 격리 Hermes 시험에서 표현을 바꾼 로그 조회와 작은 ZIP 정리를 수행하고 한글 경로·동명 사진·원본 ZIP·메모 보존을 확인했습니다. 이번 v3.7 배포 검증을 위해 사용 중인 모델이나 메신저를 재시작하지 않습니다.
- 체크포인트에는 추가 메모리 비용이 있습니다. 처음 보는 입력, 긴 출력, 대용량 파일이나 다른 모델의 성능은 다를 수 있습니다.
- 한정된 로그 조회만으로 PC 전체의 정상 상태를 증명할 수 없습니다. 모델이 일부 경고나 상태를 과하게 단정하는 오류, 검색 자료의 날짜·대상·수치를 잘못 연결하는 오류는 남아 있습니다. 모든 진단 정확도나 할루시네이션이 해결된 배포는 아닙니다.

## 기존 사용자 업데이트

1. 기존 런처에서 **AI 끄기**를 누르고 종료 완료 후 런처를 닫습니다.
2. 배포 폴더 전체를 압축 해제하고 설치 **BAT**을 관리자 권한으로 실행합니다.
3. 새 런처의 **v3.7.42**를 확인하고 **AI 켜기**를 누릅니다.
4. 모델 서버와 Hermes·메신저 연결 시작 완료를 확인합니다.

BAT 설치 또는 런처 창 재실행만으로 이미 실행 중인 모델·Hermes가 갱신되지는 않을 수 있습니다. 초기화·제거·모델 재다운로드·PC 재부팅은 필요하지 않습니다. 기존 모델·문서·대화·예약·연결 설정은 지우지 마세요.
