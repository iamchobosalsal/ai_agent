AI One-touch v3.6.63 설치 안내
================================

이 폴더에는 AI One-touch v3.6.63 설치 파일과 제거 도구가 들어 있습니다.

[처음 설치 또는 업데이트]
1. ZIP 파일 전체를 새 폴더에 압축 해제합니다.
2. package-info.json의 인증서 지문을 배포자가 안내한 값과 비교합니다.
3. 1_Install_AI_OneTouch_Internal.bat을 우클릭하여 관리자 권한으로 실행합니다.
4. 설치가 끝나면 바탕화면 또는 시작 메뉴의 AI One-touch Internal을 실행합니다.
5. 자세한 화면 설명은 AI_OneTouch_v3.6_Installation_and_Usage_Guide.html을 확인합니다.

기존 v3.6 사용자는 같은 방법으로 설치하면 설정, 내려받은 LM Studio 모델과 등록한 RAG 문서를 유지한 채 업데이트됩니다.

[이번 버전의 주요 변경]
- 대시보드의 currentLang 연결 오류 수정
- Qwen3-Embedding-0.6B Q8 기반 문서 검색
- 임베딩 모델 중복 실행 방지
- 견적 등 특정 업무에 고정되지 않는 범용 자연어 RAG
- 불필요한 다단계 모델 호출을 제거하여 응답 시간 단축
- Qwen이 내부 추론만 하고 답변을 비우는 문제 수정

[문서 RAG]
- 런처의 문서 기반 RAG 화면에서 파일을 끌어다 놓거나 파일 추가 버튼을 사용합니다.
- 문서 등록이 끝난 뒤 질문 앞에 /rag를 붙여 질문할 수 있습니다.
- 문서, 청크와 임베딩 데이터는 이 PC의 로컬 저장소에 보관됩니다.
- 지원 형식과 용량 제한은 동봉된 HTML 가이드에서 확인합니다.

[자체서명 안내]
- 이 설치본은 공인 코드서명이 아닌 내부 배포용 자체서명 MSIX입니다.
- 최초 설치 시 Trust 폴더의 공개 인증서를 Windows 인증서 저장소에 등록하므로 관리자 권한이 필요합니다.
- 인증서 지문은 package-info.json에서 확인할 수 있습니다.
- 서명용 개인키는 배포 파일에 포함되어 있지 않습니다.

[실행이 안 될 때]
1. 열려 있는 기존 런처 창과 탭을 닫고 다시 실행합니다.
2. 최신 ZIP을 새 폴더에 완전히 압축 해제한 뒤 설치 BAT을 관리자 권한으로 다시 실행합니다.
3. 계속 문제가 있으면 Reset_Tool.exe로 런처 환경을 초기화한 뒤 재설치합니다.

대시보드에 예전 오류 문구가 남아 있으면 새로고침하거나 런처를 다시 열어 주세요. currentLang 오류 때문에 Windows를 재부팅할 필요는 없습니다.

[제거]
- 3_Remove_AI_OneTouch_Internal.bat을 관리자 권한으로 실행합니다.
- 런처 데이터까지 초기화하려면 제거 전에 Reset_Tool.exe를 사용합니다.

[주의]
- 설치 중에는 런처와 LM Studio를 강제로 종료하지 마세요.
- Telegram 또는 Slack Token은 비밀번호와 같으므로 외부에 공유하지 마세요.
- 본 런처와 제3자 소프트웨어 및 모델에는 각각의 라이선스와 이용 조건이 적용됩니다.
