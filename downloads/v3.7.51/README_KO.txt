AI One-touch 3.7.51 — Hermes 모델 동기화 수정

런처에서 모델을 변경하고 AI 끄기 → AI 켜기를 했는데도 Hermes가 이전 모델을 유지하던 경로를 보완했습니다.
- 최신 Hermes 창 로딩 코드에 동기화 패치를 적용합니다.
- 기본 프로필의 이전 모델 선택과 마지막 대화 복원 정보를 초기화합니다. 대화 기록 자체는 삭제하지 않습니다.
- 화면 재로딩 확인을 받은 뒤에만 동기화 완료 표식을 기록합니다.
- 모르는 Hermes 코드 구조에서는 조용히 성공 처리하지 않고 실패를 표시합니다.

설치: 기존 AI를 끄고 런처를 닫은 뒤 ZIP 전체를 압축 해제하여 1_Install_...bat을 관리자 권한으로 실행하세요. 새 버전에서 AI를 켜면 Hermes Desktop 호환 패치 재빌드가 진행될 수 있습니다. 완료될 때까지 기다려 주세요.
모델과 문서를 초기화할 필요는 없습니다. 기존 대화는 기록에 남으며 새 대화에서 선택 모델을 확인하세요.

검증: 3.6/3.7 구문·배포 검사, 최신 Hermes 소스 패치/중복 적용, 완료 표식 이전, 렌더러 저장값 정리 및 재로딩 확인 검사 통과. 실제 PC의 모델 답변까지 검증한 결과는 아닙니다.
