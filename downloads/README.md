# 설치 파일

저장소 상단의 **Code → Download ZIP**으로 전체 파일을 내려받고 압축을 해제한 뒤, 원하는 버전 폴더에서 설치를 시작하세요.

## 권장 버전

- [v3.7.43](v3.7.43): 처음 설치하는 사용자용. 이미지 도구·기존 대화 재전송의 LM Studio 호환성 보완.
- [v3.6.95](v3.6.95): 기존 대시보드와 상세 관리 기능을 사용하는 사용자용. 같은 이미지 호환성 보완.

이번 업데이트는 **두 계열 모두** 이미지 전송 오류를 보완합니다. 새 이미지 분석뿐 아니라 이전 실패 대화와 마지막 요약 요청도 포함합니다. 사용자 원본 이미지·기존 대화는 유지하고, 메시지 형식 오류에 불필요한 대화 압축을 하지 않습니다. 파일 생성 성공과 OCR 내용의 정확성은 별개이며, 중요한 전표는 원본을 대조하세요.

**계열별 최신 버전 하나씩만 유지합니다.** 구버전 설치 폴더는 새 배포판 검증 후 현재 목록에서 제거합니다. 예전 파일은 Git 변경 이력에 남으며, 현재 설치된 사용자의 앱·문서·모델이 삭제되는 것은 아닙니다. 별도 Team AI 서버·클라이언트는 이 배포에 포함하지 않습니다.

기존 공통 수정은 유지합니다. 메신저 기본 경로의 답변 삭제·대체 후처리와 도구 선택 개입 해제, MCP 한글 UTF-8 해독과 출처 필드/줄바꿈, 알려진 k-skill 스텁의 실제 본문 로딩, 중복 설정 병합과 안전한 플러그인 등록을 포함합니다. 추가 검수 모델·검색·재임베딩은 없습니다. 검색 자료의 날짜·대상·수치를 잘못 연결하는 오류는 남아 있으며, 모든 답변의 정확성이나 속도를 보장하지 않습니다.

기존 자연어 `/rag`의 원본 표·인접 문맥 보충, 예시·업무 규칙 구분 및 반복 입력 캐시 개선도 유지합니다. 이번 이미지 호환성 수정에서는 `/rag` 엔진·모델 로딩 설정·추론/출력 예산을 변경하지 않습니다.

## 기존 사용자 업데이트 순서

1. 기존 런처에서 **AI 끄기** → 종료 완료 확인 → 런처 닫기.
2. 새 배포 폴더 압축 해제 → **설치 BAT을 관리자 권한으로 실행**.
3. 새 런처를 열고 **v3.6.95 / v3.7.43 확인 → AI 켜기**.
4. 모델 서버와 Hermes·메신저 연결 시작 완료 확인.

**BAT 설치나 런처 창 재실행만으로는 실행 중인 Hermes가 갱신되지 않을 수 있습니다.** 이미 설치했다면 런처에서 AI 끄기 → AI 켜기를 실행하세요. PC 재부팅·초기화·제거·모델 재다운로드는 필요하지 않습니다. 기존 모델·문서·대화·예약·연결 설정을 지우지 마세요.

고정 알림은 실행 시 모델 없이 전달하며, 예약 보고의 무응답은 실패로 기록합니다. PC 절전·종료, 메신저 연결 끊김 또는 전송 권한 오류가 있으면 제시간 전달되지 않을 수 있습니다. 기존 예약을 자동 재등록하거나 이미 종료된 알림을 다시 보내지는 않습니다.

각 버전 폴더의 `README_KO.txt`를 먼저 확인하고 `1_Install_...bat`을 관리자 권한으로 실행합니다.

두 설치본은 공인 코드서명이 아닌 자체서명 MSIX입니다. 설치 과정에서 `Trust` 폴더의 공개 인증서를 Windows 인증서 저장소에 등록하며, 서명용 개인키는 배포 파일에 포함되어 있지 않습니다.

설치 파일의 SHA-256 값과 인증서 지문은 각 폴더의 `package-info.json`에서 확인할 수 있습니다.
