# 설치 파일

저장소 상단의 **Code → Download ZIP**으로 전체 파일을 내려받고 압축을 해제한 뒤, 원하는 버전 폴더에서 설치를 시작하세요.

## 권장 버전

- [v3.7.36](v3.7.36): 처음 설치하는 사용자용. 메신저 예약 알림·날짜 및 근거 확인 보완 포함.
- [v3.6.88](v3.6.88): 기존 대시보드와 상세 관리 기능을 사용하는 사용자용. 동일한 예약 및 근거 확인 보완 포함.

업데이트 후 런처에서 **AI 끄기 → AI 켜기**를 한 번 실행하면 새 Hermes 코드가 반영됩니다. PC 재부팅은 필요 없습니다. 기존 연결 정보와 모델은 초기화하지 마세요.

고정 알림은 실행 시 모델 없이 전달하며, 예약 보고의 무응답은 실패로 기록합니다. PC 절전·종료, 메신저 연결 끊김 또는 전송 권한 오류가 있으면 제시간 전달되지 않을 수 있습니다. 기존 예약을 자동 재등록하거나 이미 종료된 알림을 다시 보내지는 않습니다.

각 버전 폴더의 `README_KO.txt`를 먼저 확인하고 `1_Install_...bat`을 관리자 권한으로 실행합니다.

두 설치본은 공인 코드서명이 아닌 자체서명 MSIX입니다. 설치 과정에서 `Trust` 폴더의 공개 인증서를 Windows 인증서 저장소에 등록하며, 서명용 개인키는 배포 파일에 포함되어 있지 않습니다.

설치 파일의 SHA-256 값과 인증서 지문은 각 폴더의 `package-info.json`에서 확인할 수 있습니다.
